# EGX_Terminal bootstrap kernel

EGX_Terminal is a research and design workspace for a public, LLM-agnostic
terminal-agent environment. Repository-owned behavior, knowledge, project state,
and methods must remain portable across providers and models.

## Start every mission

1. Read `docs/STATUS.md`.
2. Identify the smallest set of documents relevant to the mission.
3. Read only those documents before acting; expand context only when needed.

Do not preload all research, decisions, or repository audits.

## Current phase

The project is auditing external repositories before choosing its architecture.
Do not present provisional structures as final doctrine or implemented capability.
Audit repositories individually. Do not merge their concepts before all five
audits are complete.

## Working rules

- Separate documented evidence, interpretation, and project decision.
- Cite external ideas with exact paths, URLs, versions, or commits when available.
- Never copy an external repository blindly; extract and evaluate principles.
- Prefer short, inspectable, reversible mechanisms.
- Keep the behavioral core small. Every added rule or mechanism must justify its
  utility and context cost.
- Preserve provider and model neutrality in repository-owned concepts.
- Treat provider-specific files as replaceable compatibility adapters.
- Keep all committed content suitable for a future public repository: no secrets,
  private data, personal absolute paths, or unattributed borrowed material.
- Add no skill, hook, agent, memory system, dependency, or routing layer without a
  demonstrated need and an explicit decision.

Detailed evidence belongs in the relevant research or decision document, not in
this kernel.
